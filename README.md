# 🧟 Zombie Shooter Game



https://github.com/user-attachments/assets/8ad500bb-123d-4447-ad53-93741665144c



A lightweight **HTML5 Canvas Zombie Shooter Game** built using **Vanilla JavaScript, HTML, and CSS**.

This project demonstrates real-time game mechanics such as player shooting, enemy waves, health system, reload mechanics, and HUD interface — all without external libraries.

---

## 🎮 Demo Preview

Open the `zombie_shooter.html` file in your browser to play instantly.

---

## 🚀 Features

✅ Real-time zombie shooting gameplay  
✅ Canvas-based rendering  
✅ Wave-based enemy system  
✅ Player health system (HP bar)  
✅ Gun & ammo display  
✅ Reload mechanic with progress bar  
✅ HUD (Heads-Up Display)  
✅ Game start overlay screen  
✅ Smooth animations  
✅ Mouse aiming & shooting  

---

## ▶️ How To Run

1. Clone repository

```
git clone https://github.com/your-username/zombie-shooter.git
```

2. Open project folder

```
cd zombie-shooter
```

3. Run the game

Open `zombie_shooter.html` in any browser.

✅ No installation required.
